Leads are the people your assistants call. Orato groups them into **lead batches**, and each campaign calls one batch.

<Frame>
  ![Lead Batches page](/images/app/leads.png)
</Frame>

## The Lead Batches page

| Stat | Meaning |
| --- | --- |
| **Total batches** | Number of lead batches |
| **Total leads** | Leads across all batches |
| **Avg per batch** | Average batch size |

Use the toolbar to search batches, filter by source, sort (for example **Newest first**), and switch between grid and list views.

## Create a batch manually

<Steps>
  <Step title="Click Create batch">
    On the **Leads** page, click **Create batch** and stay on the **Manual Batch** tab.

    <Frame>
      ![Create New Lead Batch, manual](/images/app/leads-create-manual.png)
    </Frame>
  </Step>
  <Step title="Fill in the details">
    | Field | Required | Notes |
    | --- | --- | --- |
    | **Batch Name** | Yes | Up to 50 characters, for example `Q1 Property Enquiries` |
    | **Description** | No | Up to 500 characters |
    | **Color** | No | Helps you tell batches apart |
    | **Tags** | No | Type a tag and click **Add** |
  </Step>
  <Step title="Create and add leads">
    Click **Create Batch**, then use **Add lead** to add contacts to it.
  </Step>
</Steps>

## Import from CSV or Excel

<Steps>
  <Step title="Open the CSV tab">
    Click **Create batch**, then select **Batch with CSV**.

    <Frame>
      ![Create New Lead Batch, CSV import](/images/app/leads-create-csv.png)
    </Frame>
  </Step>
  <Step title="Name the batch">
    Enter a **Batch Name** and optional description and color.
  </Step>
  <Step title="Upload the file">
    Click **Download Template** for a starter file, or drag in your own. CSV, XLS, and XLSX files up to 3 MB are supported.
  </Step>
  <Step title="Create">
    Click **Create Batch with CSV**.
  </Step>
</Steps>

### File format

| Column | Required | Notes |
| --- | --- | --- |
| `name` | Yes | The lead's name. Used for `{{customer_name}}`. |
| `phone` | Yes | Include the country code, for example `+919876543210` |
| `email` | No | |
| `notes` | No | |
| Any other column | No | Saved as additional info on the lead, for example `Company` |

```csv
name,phone,email,notes,Company
Rahul Sharma,+919876543210,rahul@example.com,Enquired about 2BHK,Sharma Traders
Ananya Iyer,+919812345678,,Prefers evening calls,
```

<Tip>
  Always use full international numbers with a `+` and country code. Numbers without a country code may fail to connect.
</Tip>

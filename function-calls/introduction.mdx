## What are function calls?

By default, your AI Assistant can only talk. Function calls give it the ability to _do things_ during a live conversation, check a calendar, book a meeting, transfer the call to a human, or call an external API to fetch data.

When a caller says _"I'd like to book a time"_, your assistant doesn't just say _"okay"_, it actually checks your calendar, finds an open slot, and confirms the booking. Right there on the call.

## How it works

<Steps>
  <Step title="You define a tool in the assistant's Tools Tab">
    In **AI Assistants → Setup → Tools Tab**, you add the tools your assistant can use. Each tool has a name, a description, and the action it performs.
  </Step>
  <Step title="Your instructions tell the assistant when to use it">
    In your assistant's instructions, you write the conditions under which it should trigger a tool. For example: _"If the caller wants to book a meeting, use the calendar booking tool."_
  </Step>
  <Step title="The assistant triggers the tool mid-call">
    When the condition is met during a live conversation, the assistant pauses, runs the function, gets the result, and incorporates it naturally into its response — all in real time.
  </Step>
</Steps>

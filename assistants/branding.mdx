The **Branding** tab appears when an assistant's role is **Web Widget**. It controls how the widget looks on your website. A live preview on the right updates as you edit; click **Create Assistant** (or save) to apply changes to your site.

<Frame>
  ![Branding tab with live widget preview](/images/app/assistant-branding.png)
</Frame>

The widget lets visitors choose between **Start a call** (talk in real time) and **Send a message** (type instead of speaking). Both channels stay available whatever copy you change.

## Colors and placement

| Field | What it controls |
| --- | --- |
| **Brand** | Main accent color, used on the header and primary button |
| **Panel background** | Background of the widget panel |
| **Launcher** | Color of the floating button |
| **Header text** | Text color in the header |
| **Launcher shape** | **Circle** or **Pill** |
| **Corner on the page** | Where the launcher sits, for example **Bottom right** |
| **Logo** | Upload a PNG, JPG, or WebP up to 1 MB, or paste a public image URL |

## Start screen copy

Text shown when a visitor opens the widget. Fields are pre-filled so you can see where they appear. Clear any field to hide it.

| Field | Default |
| --- | --- |
| **Welcome message** | Choose a channel to continue. |
| **Eyebrow** | Assistant |
| **Headline** | How can `{name}` help? (`{name}` is replaced by the agent name) |
| **Call label** / **Call hint** | Start a call / Talk in real time |
| **Chat label** / **Chat hint** | Send a message / Type instead of speaking |

## Legal and install

| Field | What it does |
| --- | --- |
| **Privacy Policy URL** | Adds a privacy link to the widget. Leave blank to hide. |
| **Terms URL** | Adds a terms link. The legal line appears only when a URL is set. |

Save the assistant to get its install snippet, then follow [Widget integration](/developer/widget-integration).

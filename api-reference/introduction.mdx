## Authentication

Orato uses two kinds of keys. Create them in **Developer → API Keys**.

| Key | Prefix | Where to use it |
| --- | --- | --- |
| Public | `pk_live_` | In the browser, with the website widget. Restricted to whitelisted domains. |
| Secret | `sk_live_` | On your server only. Grants full access to your account. |

<Warning>
  Treat secret keys like passwords. Never put them in frontend code, mobile apps, or public repositories.
</Warning>

## Widget quick start

```html
<script
  src="https://app.tryorato.com/widget.js"
  data-key="pk_live_YOUR_PUBLIC_KEY"
  data-assistant="YOUR_ASSISTANT_ID"
  defer
></script>
```

See [Widget integration](/developer/widget-integration) for programmatic setup and troubleshooting.

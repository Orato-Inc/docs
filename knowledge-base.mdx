The knowledge base holds the information your assistants look up during conversations: product details, pricing, FAQs, policies, and scripts. Add content once, then attach it to any assistant.

<Frame>
  ![Knowledge base page](/images/app/knowledge-base.png)
</Frame>

## Limits

| Limit | Value |
| --- | --- |
| File types | PDF, TXT, DOCX |
| Max file size | 2 MB per file |
| File uploads | 10 files per workspace |
| Organization storage | 5 MB total, across files and website pages |

Imported website pages count toward organization storage but **never** use file upload slots.

## Upload documents

<Steps>
  <Step title="Open Knowledge Base">
    Click **Knowledge Base** in the sidebar.
  </Step>
  <Step title="Upload">
    Drag files onto the upload area, or click it to browse.
  </Step>
  <Step title="Wait for processing">
    Each file appears under **Documents** with its type, size, token count, and status. A document can be attached to assistants once it's ready.
  </Step>
</Steps>

## Import a website

<Steps>
  <Step title="Click Import website">
    Enter your site URL, for example `https://example.com`.

    <Frame>
      ![Import website dialog](/images/app/knowledge-base-import.png)
    </Frame>
  </Step>
  <Step title="Find pages">
    Click **Find pages**. Orato lists the best pages from the site.
  </Step>
  <Step title="Pick pages">
    Select the pages to add. They're crawled and indexed into your knowledge base.
  </Step>
</Steps>

<Tip>
  You can also import a website directly from an assistant's **Prompt** tab with **Import from website**. Orato adds the pages to the knowledge base and helps you confirm business facts for the prompt.
</Tip>

## Attach knowledge to an assistant

Open the assistant, go to the **Advanced** tab, and select documents under **Knowledge documents**. Ready documents are searched on calls and in widget chats.

## Write documents that work well

- **One topic per document.** Separate pricing, FAQs, and policies so search finds the right one.
- **Use plain language.** Write facts the way you'd say them on a call.
- **Use question-and-answer format** for FAQs.
- **Keep it current.** Replace outdated files so the assistant never quotes old prices.
- **Remove noise.** Strip headers, footers, and boilerplate that waste storage.

<Warning>
  Your assistant can only be as accurate as its documents. Tell it in **Guardrails** not to guess when the answer isn't in its knowledge.
</Warning>

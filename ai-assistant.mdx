An AI Assistant is a voice agent configured for one job: qualifying leads, answering support calls, booking appointments, or helping website visitors. You set it up once, and it handles every conversation the same way.

<Frame>
  ![AI Assistants page](/images/app/assistants.png)
</Frame>

## The Assistants page

Go to **AI Assistants** in the sidebar. The page shows:

- **Your assistants**: every assistant in your workspace. Use the search box to find one by name or ID.
- **Agent templates**: ready-made starting points for common use cases. See [Assistant templates](/assistant-templates).

## Create an assistant

Click **+ Create Assistant**, or click a template to start with its prompt pre-filled. The editor has these tabs:

<CardGroup cols={2}>
  <Card title="Prompt" icon="file-lines" href="/assistants/prompt">
    Agent name, first message, and instructions. Generate a prompt, import from your website, or translate it.
  </Card>
  <Card title="Voice" icon="microphone" href="/assistants/voice-and-language">
    Voice provider, model, voice, speed, primary language, and automatic language switching.
  </Card>
  <Card title="Settings" icon="sliders" href="/assistants/settings">
    Role, caller ID or inbound number, AI model, temperature, who speaks first, and interruption sensitivity.
  </Card>
  <Card title="Branding" icon="palette" href="/assistants/branding">
    Colors, logo, and copy for the website widget. Shown only for Web Widget assistants.
  </Card>
  <Card title="Advanced" icon="gear" href="/assistants/advanced">
    Transcriber, call limits, end call phrases, recording, transfer to a human, ticketing, and knowledge documents.
  </Card>
</CardGroup>

When you're done, click **Create Assistant**. Click **Cancel** to leave without saving.

## Live cost estimate

The top of the editor shows the estimated cost per minute in USD and INR, split into **Transcriber**, **LLM**, **Voice**, and **Platform**. It updates as you change providers and models.

## Roles at a glance

| Role | Use it to | You'll need |
| --- | --- | --- |
| **Outbound** | Call leads from campaigns or the **Make call** button | An **Outbound caller ID** (a number you own) |
| **Inbound** | Answer calls to your business number | An **Inbound phone number** |
| **Web Widget** (beta) | Talk or chat with website visitors | A public API key and the widget script |

You can test any assistant in the browser before you connect a number.

## Test your assistant

Use **Talk** in the assistant editor to have a live voice conversation in your browser. Talk uses the voice and speed you selected on the **Voice** tab. After testing, review the transcript in [Conversations](/conversations) and refine the prompt.

<Tip>
  Test the hard cases, not only the happy path: a caller who is busy, one who asks for a human, one who asks about pricing, and one who switches language.
</Tip>
